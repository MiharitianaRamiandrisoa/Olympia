OLYMPIA — Décorations de Noël SVG

Contenu :
- branche-sapin.svg : branche à placer en haut à droite
- boules-noel.svg : boules suspendues
- flocon.svg : flocon à dupliquer et redimensionner
- etoile.svg : petite étoile décorative
- cadeau.svg : cadeau à placer en bas du hero
- guirlande-lumineuse.svg : guirlande discrète
- arc-dore.svg : courbe dorée pour le haut du hero
- olympia-noel-sprite.svg : symboles SVG réutilisables en inline

Exemple HTML :
<img src="/images/noel/flocon.svg" class="deco deco-flocon" alt="" aria-hidden="true">

Exemple CSS :
.deco { position:absolute; pointer-events:none; user-select:none; z-index:2; }
.deco-flocon { width:42px; opacity:.65; }
.hero { position:relative; overflow:hidden; }

Palette : bleu pétrole #0D5360, teal #146675, beige/doré #DDC9A4.
Les SVG ont un fond transparent et peuvent être redimensionnés sans perte de qualité.
